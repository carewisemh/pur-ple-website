# Pur_Ple Website

A responsive single-page website preview for Pur_Ple, Purposeful People, based in Osun State, Nigeria.

## Preview scope

- Static responsive HTML with accessible navigation and reduced-motion support.
- Core sections: Home, About, Programmes, Our Work, Get Involved, Contact, Privacy and Safeguarding.
- Online donations are intentionally disabled.
- `robots.txt` blocks crawler indexing while the site is under review.

## Before public launch

Review the privacy notice, approve image permissions and safeguarding checks, verify event details, connect any required contact-form workflow, configure payment processing only after account verification, and remove the preview crawler block once approved.

The full Next.js implementation and event-image assets are available in the Stage 2 website bundle supplied in the project conversation.
